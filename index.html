Getting a deck into Canva

Print the deck to PDF

Open the deck in Chrome, ⌘/Ctrl + P → Save as PDF, enable Background graphics, margins None. The print stylesheet renders every slide as its own 1280 × 720 page — builds revealed, notes and chrome removed.

Import into Canva

Canva → Upload → drop the PDF. Each page becomes an editable slide with live text, so you can restyle, add brand assets or record a voiceover there.

Or export PNGs

For image-only import: print each slide at 1280 × 720, or screenshot the stage — node .scratch/verify.js in this folder renders every deck headlessly and writes PNGs to .scratch/shots/.

What Canva does not keep: the interactivity. Widgets, quizzes and the timer live in the HTML — present the deck from a browser, and use the Canva version as the leave-behind, the handout or the rehearsal copy. Keep both from the same source so they cannot drift.
